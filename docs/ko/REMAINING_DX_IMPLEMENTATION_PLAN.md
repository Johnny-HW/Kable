# 남은 개발자 사용성 개선 실행 계획

2026-10-01. 사용자의 미적용 항목 적용 요청을 승인 범위로 한다.

1. 기본 요청 제한시간: `KableClientBuilder.cs`가 `DefaultRequestTimeoutMs`를 세션에 전달하고, 신규 `KableSessionRequestExtensions.cs`의 동일 메시지 타입 요청 API가 기본값과 명시값을 적용한다. 기존 인터페이스 구현자의 변경을 요구하지 않는다.
2. 고급 빌더: 세션·하트비트 옵션 전달을 추가한다. `Cases/Configuration/BuilderOptionsTests.cs`에서 제한시간, 큐, 하트비트의 실제 동작을 먼저 검증한다.
3. 자동 복구: 신규 `Simple/Reconnecting/`의 옵션과 클라이언트에 한정한다. 새 연결을 생성하고 구독을 유지하며 명령 재전송은 하지 않는다. 재시도 횟수·간격·취소·종료를 명시한다. 대응 테스트는 `Cases/Simple/Reconnecting/`에 둔다.
4. 문자열 코덱: 송신 임시 배열 제거를 인코딩·구분자·빈 문자열 테스트로 검증한다. 수신 문자열 할당은 유지한다.
5. 벤치마크: 코덱·세션 측정을 분리하고 비동기 준비/종료를 사용한다. Release에서 측정하고 환경·결과·측정 범위를 기록한다.
6. 문서: API 사용법, 이벤트/UI 계약, 복구와 성능 범위를 작성한다. 누락된 최상위 SSOT 경로에는 실제 언어별 문서 링크를 제공한다. 기존 보고서에 완료 상태와 검증 한계를 덧붙인다.

추가 파일은 각 300줄 미만으로 유지한다. 기존 Simple 파사드의 내부 클라이언트는 별도 파일로 분리한다. 관련 선행 테스트 → 최소 구현 → 세 타깃 빌드 → 관련/전체 테스트 순서로 검증하고 검증 단위마다 마이크로 커밋한다. 실패로 사용자 변경을 제거하지 않는다.
