# Kable 1.9.1 release notes

Release date: **2026-10-26**.
[GitHub release](https://github.com/Johnny-HW/Kable/releases/tag/v1.9.1) ·
[NuGet](https://www.nuget.org/packages/Kable/1.9.1) · [한국어](1.9.1.ko.md)

## Fixed

Concurrent `StartAsync` callers that did not cancel now receive the original connection
failure even when session cleanup cancels their linked waiting token. The completed shared
startup result remains authoritative instead of being hidden by internal cleanup cancellation.

Explicit caller cancellation remains isolated to that caller. Stop/Dispose still interrupt
waiters while a connection is pending, including when the connection factory ignores its token.
General request waiting, FIFO/CID routing and public API signatures are unchanged.

The regression is exercised in an isolated process with controlled scheduling. This avoids
changing the test runner's thread pool and reproduces the actual startup failure path.
The publishing workflow now requires this regression check before creating packages.

## CI and upgrade

Automatic library CI now runs on **Windows only**. The Linux test job has been removed.
NuGet publishing continues through the Windows runner. Existing netstandard2.0, net8.0,
net10.0 and Windows-specific package targets are retained; this change does not remove
runtime assets or change framework compatibility claims into new test guarantees.
The separate GitHub Pages documentation deployment is unaffected.

```bash
dotnet add package Kable --version 1.9.1
```

This is a patch release for the 1.9.0 startup-error race. Existing interfaces and constructors
remain compatible. Uncommitted Protocol Pack work is excluded, as in 1.9.0.

The isolated release checkout passed all **412 tests across 12 projects**, with a warning-free
Release build and three controlled startup-race executions. The release contains 13 packages.

See the [fix verification](../development/2026-10-26-start-failure-outcome/verification.md)
for the development history and [release verification](../development/2026-10-26-release-1.9.1/verification.md)
for checks against the committed release contents.
