# Kable 1.10.0 릴리즈 노트

상태: 배포 후보. 업로드 후 게시 검증 결과를 기록한다.

## 추가 기능

- Kable.Core에 IKableServer<TMessage>, IServerSession<TMessage> 계약 추가.
- Kable에 서버 빌더와 엔진 추가: 리스너 소유권, 연결별 코덱·ID, 접속·수신·종료 이벤트,
  개별 전송 및 유한 큐 기반 브로드캐스트.
- 정확한 세션 큐 용량, 최대 접속 수, 브로드캐스트 제한시간, 정상 송신 드레인과 기한 후 Abort.
  동시 Stop/Dispose는 정리를 공유한다.
- PacketTraceRecord에 선택적인 ConnectionId 생성자 추가. 기존 생성자는 유지하고 null을 반환한다.

## 사용과 호환성

게시 후 `dotnet add package Kable --version 1.10.0`으로 설치하고 확장 모듈의 버전도 맞춘다.
Core/Kable의 netstandard2.0, .NET 8/10 지원과 기존 클라이언트 FIFO/CID 수명 계약은 유지한다.
서버 SendAsync 성공은 큐 등록이며 네트워크 전달 완료가 아니다. 브로드캐스트 취소 전 일부 메시지가
등록될 수 있다. 문자열·이벤트·스냅샷은 할당하므로 서버 전체를 0-GC로 표현하지 않는다.

[다중 클라이언트 서버 가이드](../ko/SERVER_HOSTING.md)에 TCP 예제, 옵션, 전송 소유권,
이벤트 처리와 취소·종료 계약을 정리했다. 서버 요청/응답 상관 처리, TLS 협상과 인증은
이 빌더에서 제공하지 않는다.

## 검증

서버 테스트 36개로 수명, 개별 전송, 순서, 실제 큐 포화, 용량, 접속 제한, 코덱 장애·진행 여부,
이벤트 격리와 TCP 종료를 검증했다. 패키지 콘솔 소비자는 .NET 8/10에서 새 서버 API도 실행한다.
전체 솔루션·샘플·패키지 검증 결과는 릴리즈 작업 보고서에 기록한다.
실장비와 장기간 부하 시험은 이번 검증에 포함하지 않는다.
