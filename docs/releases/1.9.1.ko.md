## 수정

동시에 `StartAsync`를 호출하다 연결이 실패했을 때, 취소하지 않은 호출자는
세션 정리용 취소 신호 대신 원래 연결 오류를 받도록 수정했다.
완료된 공유 시작 결과가 내부 정리용 취소에 가려지지 않도록 한다.

호출자가 직접 취소한 대기는 취소로 끝난다. Stop/Dispose는 연결이 진행 중일 때
대기 호출자를 계속 중단하며, 연결 팩토리가 취소를 무시하는 경우도 검증한다.
일반 요청 대기, FIFO/CID 라우팅과 공개 API 서명은 변경하지 않았다.

별도 프로세스에서 실행 순서를 제어하는 재현 검사를 추가했다. 테스트 실행기의
스레드 풀에는 영향을 주지 않는다. 게시 워크플로도 이 검사를 통과해야 패키지를 생성한다.

## CI와 업그레이드

라이브러리 자동 CI는 **Windows만 실행**한다. Linux 테스트 작업은 제거했고,
NuGet 게시도 Windows 실행기에서 수행한다. 기존 netstandard2.0·net8.0·net10.0 및
Windows 전용 패키지 대상은 유지한다. 런타임 자산을 삭제하거나 Linux 호환성을
새로 검증했다는 의미는 아니다. 별도 GitHub Pages 문서 배포는 유지한다.

```bash
dotnet add package Kable --version 1.9.1
```

1.9.0의 시작 오류 경합을 고친 패치 버전이며 기존 인터페이스와 생성자는 유지한다.
미커밋 Protocol Pack 작업은 1.9.0과 동일하게 배포에서 제외한다.

분리한 릴리즈 체크아웃에서 **12개 프로젝트의 테스트 412개**가 모두 통과했다.
Release 빌드는 경고·오류가 없으며 제어 재현 검사도 3회 통과했다. 패키지는 13개다.

개발 과정은 [수정 검증 기록](../development/2026-10-26-start-failure-outcome/verification.md),
릴리즈 대상 소스의 점검 결과는 [릴리즈 검증 기록](../development/2026-10-26-release-1.9.1/verification.md)을 참고한다.
