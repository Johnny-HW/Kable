# Kable 1.10.1

2026-10-29. Published to NuGet.org and GitHub Packages. [CI verification](https://github.com/Johnny-HW/Kable/actions/runs/40816337009).

## Fixes

- Close FIFO sessions when send tracing fails before a response is confirmed.
- Preserve FIFO DeviceTimeoutException when timeout tracing or message formatting fails. Diagnostic errors are retained in Exception.Data.
- Keep heartbeat timeout monitoring active while Ping writes are stalled; close the session if Ping creation fails.
- Reject binary payloads exceeding configured limits or the two-byte length field before writing output.
- Use the configured TimeProvider for request deadlines on .NET 8/10. netstandard2.0 retains system timers.

Public interfaces and target frameworks are unchanged. Outbound payloads previously accepted despite invalid lengths now throw ArgumentOutOfRangeException.
Regression tests cover formatting/observer failures, blocked Ping flushes, and length boundaries. No hardware or long-duration load testing is claimed.
