# Kable 1.9.2 release notes

Status: **planned / release preparation**. Release date is not set. No packages or tags are published by this version update.

## Planned contents

- YAML Protocol Pack loader, validator and roundtrip persistence (`Kable.ProtocolPack`).
- AdditionalFiles source generation for AsciiLine commands, reply enums, endpoint option factories and Modbus/MELSEC map constants.
- Modbus RTU request/response framing for supported function codes and MELSEC SLMP 3E binary request/response encoding and decoding.
- Shared-memory UI session reconnection without restarting devices, with fault and performance verification recorded separately.
- Modbus TCP Coil operations, a Serial RTU master, named devices and scaled PLC tags.
- Serial cancellation/cleanup, TCP TLS/mTLS, bounded MQTT/OPC UA subscriptions and subscription recovery.
- Strict OPC UA endpoint policy selection, certificate trust and username/certificate user identities.
- .NET 8 and .NET 10 support and runtime tests for Modbus, MQTT and OPC UA.

## Upgrade and limits

All projects inheriting `Directory.Build.props` use version 1.9.2. After publication, use matching package versions, including `Kable.Generators` when generating commands. The new Protocol Pack package targets netstandard2.0.

Reply enums do not parse incoming responses. Map constants do not provide typed read/write helpers. FIFO timeout and session lifetime contracts remain in force. See the [Protocol Pack usage and limits (Korean)](../PROTOCOL_PACK_USAGE.md) and [shared-memory reconnect results (Korean)](../ko/SHARED_MEMORY_RECONNECTION_RESULTS.md).

The OPC UA Options/DI path now defaults to SignAndEncrypt, Basic256Sha256 and strict certificate validation.
The string constructor retains the legacy anonymous, unsecured path. Configure server policies and PKI before
migrating to Options. Username credentials require encryption; development trust opt-in does not permit expired
certificates or hostname mismatches.

Windows validation on 2026-10-28 passed the full Release solution build without warnings/errors and 791 test
executions across 13 test projects (667 distinct tests plus 124 additional .NET 8 executions). QuickStart,
Host, ConfigStudio and shared-memory sample smoke checks passed. All 14 local product packages passed metadata
inspection and isolated .NET 8/10 console/WPF consumer runs; each WPF run loaded 12 controls.
Physical hardware, long-term operation and other OSes remain outside this validation. No publication or tags were created.
