# Kable 1.9.2 release notes

Status: **planned / release preparation**. Release date is not set. No packages or tags are published by this version update.

## Planned contents

- YAML Protocol Pack loader, validator and roundtrip persistence (`Kable.ProtocolPack`).
- AdditionalFiles source generation for AsciiLine commands, reply enums, endpoint option factories and Modbus/MELSEC map constants.
- Modbus RTU request/response framing for supported function codes and MELSEC SLMP 3E binary request/response encoding and decoding.
- Shared-memory UI session reconnection without restarting devices, with fault and performance verification recorded separately.

## Upgrade and limits

All projects inheriting `Directory.Build.props` use version 1.9.2. After publication, use matching package versions, including `Kable.Generators` when generating commands. The new Protocol Pack package targets netstandard2.0.

Reply enums do not parse incoming responses. Map constants do not provide typed read/write helpers. FIFO timeout and session lifetime contracts remain in force. See the [Protocol Pack usage and limits (Korean)](../PROTOCOL_PACK_USAGE.md) and [shared-memory reconnect results (Korean)](../ko/SHARED_MEMORY_RECONNECTION_RESULTS.md).

The preceding documentation verification passed 438 tests across five projects. That result is not a complete 1.9.2 release certification. The version-update check passed `dotnet build Kable.sln -c Release --nologo -v quiet` with zero warnings and errors. Package-consumer checks, final release tests and publishing remain release tasks.
