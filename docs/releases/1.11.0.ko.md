# Kable 1.11.0 릴리즈 노트

2026-11-23. 전체 14개 제품 패키지(`Kable`, `Kable.Core`, `Kable.Generators`, `Kable.ProtocolPack`, `Kable.Modbus`, `Kable.Melsec`, `Kable.Mqtt`, `Kable.OpcUa`, `Kable.Grpc`, `Kable.Transport.Ipc`, `Kable.SharedMemory`, `Kable.Engine.Disruptor`, `Kable.Observability.OpenTelemetry`, `Kable.UI.Wpf`)의 보안 기본값 강화, 수명주기·동시성 안정화, 증분 생성기 수정, 패키징 고도화 및 WPF 개선 릴리즈다.

## 보안 및 기본값 강화

- **`PathAndHashLaunchGuard` (Fail-Closed)**: 허용 목록이 비어 있으면 실행을 전면 거부하도록 변경하고, 파일명보다 전체 경로 매칭을 우선하며, `AllowedSha256Hashes` 설정 시 해시 검증을 강제한다.
- **`IpcNamedPipe` (`CurrentUserOnly`)**: .NET 8/10에서 기본 파이프 ACL을 `PipeOptions.CurrentUserOnly`로 제한한다. Windows 서비스 ↔ UI 간 이종 계정 통신이 필요하면 새로 추가된 `bool currentUserOnly` 생성자 오버로드로 명시적으로 opt-in한다.
- **`GuardedProcessLauncher`**: 위험 환경변수(`PATH`, `DOTNET_STARTUP_HOOKS`, `*PROFILER*`, `LD_PRELOAD`, `COMSPEC` 등) 주입 차단, `WorkingDirectory` 정규화·존재 검증, `LaunchCommand.RedirectStandardStreams` 기본값 `false` 전환, 프로세스 종료 핸들러의 `async void` 제거를 적용했다.
- **`Kable.ProtocolPack`**: `Save` 시 경로 탐색(`..`, 루트 경로)을 차단하고, 포트/보레이트·맵 주소/포인트/범위·`csharp.namespace`/`typeKind`·파라미터 타입 검증을 보강했다.

## 안정성·수명주기·프로토콜 개선

- **공유 메모리 (`Kable.SharedMemory`)**: `SharedMemoryRingBuffer` 및 `SharedMemoryWaveformBuffer`에서 음수·역전·용량 초과 `Head`/`Tail` 오프셋을 unsafe 포인터 접근 전에 차단하고, `SharedMemoryWaveformBuffer`에 원자적 참조 카운트 리스·stale `AutoReset` 신호 재확인·중복 커널 이벤트 감지를 적용했다.
- **세션 엔진·코어 (`Kable`, `Kable.Core`)**: 종료 시 알람 스풀 유실 방지, `StartAsync` 타임아웃 연결 정리, 취소된 스트림의 hot-spin 방지, `TimeProvider` 타임스탬프 단위 불일치 수정, `KableLocalizer` 스레드 안전화, `SingleFlightConcurrencyGuard` 참조 카운트 기반 정리, `NamedPipe`/`Tls`/`SerialPort` 해제 보강, `PcapWriter` UTC 정규화·버퍼 재사용, OTel 3채널 완료 처리 및 `SpscRingBuffer` 용량 검증을 반영했다.
- **프로토콜·트랜스포트**: MELSEC SLMP·Modbus TCP 송신 16비트 길이 검증 추가, gRPC 서버 스트림/CTS 누수·클라이언트 연결 토큰 수명·5종 RPC 인증 헤더 불변성 수정, MQTT 미연결 시 QoS 1/2 `DeviceDisconnectedException` Fail-Fast(QoS 0 경고+드롭)·TLS/인증 옵션 추가, OPC UA 재연결 시 이전 `KeepAlive` 해제 및 세션 정리를 적용했다.
- **소스 생성기 (`Kable.Generators`)**: 값 동등성 기반 `CommandModel`로 Roslyn 증분 캐싱 복구, 명령별 출력과 `FormattableString.Invariant` 적용, non-partial 타입 `KABLEGEN001` 진단 보고, 루트 레벨 ProtocolPack 바인딩·제어문자/C# 예약어 이스케이프·중복 상수/열거형 충돌 루프를 수정했다.
- **WPF & ConfigStudio (`Kable.UI.Wpf`, `Kable.ConfigStudio`)**: 상시 텔레메트리 이중 로깅 및 단위 누락 수정, 텔레메트리/알람 `FilterText` 필터 연결, `RawPacketLogStreamViewModel` 50ms 배치 플러시 적용, `VirtualDeviceSimulator.Stop()` 및 시리얼 라이브 테스트의 UI 스레드 블로킹 제거, `PacketLogGrid` 공통화·`IosTheme` 300줄 미만 분할 및 `po:Freeze="True"` 적용, `Kable.UI.Wpf.Tests` 단위 테스트 프로젝트를 신설했다.

## 패키징 및 빌드

- 중앙 패키지 관리(`Directory.Packages.props`)를 도입하고 TFM별 `Microsoft.Extensions.*`(`netstandard2.0`/`net8.0` → `8.0.0`, `net10.0` → `10.0.8`)와 GA `System.IO.Ports`로 정렬했다.
- 모든 라이브러리 패키지에 XML 문서(`lib/*/*.xml`), 심볼 패키지(`.snupkg`), Portable PDB, 내장 .NET SDK SourceLink를 포함한다.
- 레거시 `OpcUaClientBridge(string, ...)` 생성자와 미구현 생성기 특성 4종(`[DeviceCommandReply]`, `[DeviceRpc]`, `[DeviceStream]`, `[DeviceAlarm]`)은 호환성을 유지한 채 `[Obsolete]`로 표시했다.

## 업그레이드 확인 사항

- **LaunchGuard**: `PathAndHashLaunchGuard` 사용 시 허용할 실행 파일 목록(`AllowedExecutables`)을 명시적으로 설정해야 한다.
- **IPC Named Pipe**: 서로 다른 계정(예: Windows 서비스 ↔ 사용자 UI) 간 파이프 통신에는 `currentUserOnly: false` 오버로드를 사용한다.
- **MQTT QoS 1/2**: 미연결 상태에서 QoS 1/2 발행을 호출하면 이제 조용히 무시되지 않고 `DeviceDisconnectedException`을 던진다.
- **GuardedProcessLauncher**: 표준 출력/오류를 읽으려면 `LaunchCommand.RedirectStandardStreams = true`를 명시한다.
