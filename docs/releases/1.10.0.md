# Kable 1.10.0 release notes

Status: release candidate; publication verification is recorded after uploading.

## Added

- `IKableServer<TMessage>` and `IServerSession<TMessage>` contracts in Kable.Core.
- `KableServerBuilder<TMessage>` and KableServer in Kable: listener ownership, per-connection
  codecs, connection IDs, lifecycle/message events, targeted sends and bounded broadcasts.
- Exact per-session queue capacity, connection limits, broadcast deadlines, graceful outgoing
  drain and abort after the shutdown drain deadline. Stop/dispose share cleanup.
- Optional ConnectionId on PacketTraceRecord through a new constructor; the existing constructor
  is preserved and sets ConnectionId to null.

## Usage and compatibility

Install `dotnet add package Kable --version 1.10.0` after publication and align all Kable modules.
Core/Kable continue targeting netstandard2.0, .NET 8 and .NET 10. Existing client APIs and
FIFO/CID lifetime contracts remain unchanged. New server queues acknowledge acceptance,
not network delivery. Broadcasts may partially enqueue before cancellation. Server strings,
events and snapshots allocate; no end-to-end zero-allocation claim is made.

Read [server hosting](../en/SERVER_HOSTING.md) for a complete TCP example, options, transport
ownership, callback restrictions, cancellation and shutdown semantics. Server request/reply
correlation, TLS negotiation and authentication are not supplied by the builder.

## Validation

36 server tests cover lifecycle, addressing, ordering, actual slow-client backpressure, exact
queue capacity, connection limits, codec failures/progress, event isolation and real TCP shutdown.
The package console consumer also exercises the new server API on .NET 8 and .NET 10.
Full solution, sample and package validation results are recorded in the release walkthrough.
Physical hardware and long-duration load testing are outside this release validation.
