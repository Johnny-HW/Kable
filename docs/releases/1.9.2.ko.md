# Kable 1.9.2 릴리즈 노트

상태: **NuGet 게시 완료, 2026-10-28**. [Kable 1.9.2](https://www.nuget.org/packages/Kable/1.9.2)를 포함한 제품 패키지 14개가 공개됐다. [게시·공식 피드 검증 결과](../development/2026-10-28-nuget-publication/walkthrough.md).

## 변경 사항

- YAML Protocol Pack 로더·검증기·라운트립 저장 (`Kable.ProtocolPack`).
- AdditionalFiles에서 AsciiLine 명령·Reply enum·endpoint 옵션 팩토리·Modbus/MELSEC 맵 상수 생성.
- 지원 FC의 Modbus RTU 요청/응답 프레이밍과 MELSEC SLMP 3E 바이너리 요청/응답 인코드·디코드.
- 장비 재시작 없이 공유 메모리 UI 세션 재연결. 장애·성능 검증 결과는 별도 문서에 기록.
- Modbus TCP Coil 기능, Serial RTU Master, 이름별 장비 관리와 PLC 자료형·배율·단위 태그.
- 시리얼 연결 취소·자원 정리, TCP TLS/mTLS, 유한 MQTT/OPC UA 구독 큐와 자동 구독 복원.
- OPC UA 보안 모드·정책의 정확한 선택, 신뢰 저장소와 사용자명/인증서 인증.
- Modbus·MQTT·OPC UA의 .NET 8/.NET 10 지원 및 양 런타임 테스트.

## 업그레이드와 제약

`Directory.Build.props`를 상속하는 프로젝트의 버전은 1.9.2다. 명령 생성에 사용하는 `Kable.Generators`를 포함해 패키지 버전을 맞춘다. 새 Protocol Pack 패키지는 netstandard2.0을 대상으로 한다.

Reply enum은 수신 응답 파서가 아니며 맵 상수는 typed RW 헬퍼를 제공하지 않는다. FIFO 타임아웃과 세션 수명 계약은 유지된다. [Protocol Pack 사용법·제약](../PROTOCOL_PACK_USAGE.md), [공유 메모리 재연결 검증](../ko/SHARED_MEMORY_RECONNECTION_RESULTS.md)을 참고한다.

OPC UA Options/DI 경로는 SignAndEncrypt·Basic256Sha256와 엄격한 인증서 검증이 기본이다.
기존 문자열 생성자는 익명·비보안 호환 경로를 유지한다. 서버 정책과 PKI를 설정한 뒤 Options API로 전환한다.
사용자명/암호는 암호화 채널에서만 허용하며, 개발용 미신뢰 인증서 허용도 만료·호스트명 오류를 허용하지 않는다.

2026-10-28 Windows 검증: 전체 솔루션 Release 빌드 경고·오류 0, 13개 테스트 프로젝트에서
815회 실행(고유 테스트 689개 + .NET 8 재실행 126회)이 모두 통과했다.
QuickStart·Host·ConfigStudio 및 공유 메모리 재연결 샘플 실행, 14개 로컬 NuGet 패키지 검사와
격리 소비자의 .NET 8/10 콘솔·WPF 실행도 통과했다. WPF는 런타임별 컨트롤 12개를 로드했다.
이는 물리 장비·장기 운전·다른 OS의 인증을 뜻하지 않는다. 게시와 공식 피드 소비 검증은 별도 결과 문서에 기록했다.
