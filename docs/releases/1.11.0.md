# Kable 1.11.0

2026-11-23. Published all 14 product packages (`Kable`, `Kable.Core`, `Kable.Generators`, `Kable.ProtocolPack`, `Kable.Modbus`, `Kable.Melsec`, `Kable.Mqtt`, `Kable.OpcUa`, `Kable.Grpc`, `Kable.Transport.Ipc`, `Kable.SharedMemory`, `Kable.Engine.Disruptor`, `Kable.Observability.OpenTelemetry`, `Kable.UI.Wpf`) to NuGet.org and GitHub Packages. [CI verification](https://github.com/Johnny-HW/Kable/actions/runs/45117487005).

## Security & Hardened Defaults

- **`PathAndHashLaunchGuard` (Fail-Closed)**: An empty allowlist now denies execution by default instead of allowing all paths; full path matching is evaluated before filename matching, and SHA-256 verification is enforced whenever `AllowedSha256Hashes` is configured.
- **`IpcNamedPipe` (`CurrentUserOnly`)**: Named pipe servers and clients on .NET 8/10 default to `PipeOptions.CurrentUserOnly`. Binary-compatible constructor overloads accepting `bool currentUserOnly` are provided for explicit cross-account Windows Service ↔ UI opt-in.
- **`GuardedProcessLauncher`**: Blocks dangerous environment variable overrides (`PATH`, `DOTNET_STARTUP_HOOKS`, `*PROFILER*`, `LD_PRELOAD`, `COMSPEC`, etc.), canonicalizes and validates `WorkingDirectory`, defaults `LaunchCommand.RedirectStandardStreams` to `false`, and eliminates `async void` on process exit handling.
- **`Kable.ProtocolPack`**: Blocks path traversal (`..` and rooted paths) during `Save`, validates `Endpoint.Port`/`BaudRate`, `Map` address/points/range bounds, `csharp.namespace`/`typeKind` allowlists, and `param.type`.

## Reliability, Lifecycles & Protocols

- **Shared Memory (`Kable.SharedMemory`)**: Guards `SharedMemoryRingBuffer` and `SharedMemoryWaveformBuffer` against negative/inverted/overflowing `Head`/`Tail` offsets before unsafe pointer indexing; converts `SharedMemoryWaveformBuffer` wait/dispose coordination to an atomic ref-counted lease with stale `AutoReset` signal re-verification and duplicate kernel event detection.
- **Session Engine & Core (`Kable`, `Kable.Core`)**: Preserves alarm spool delivery on shutdown, cleans up timed-out `StartAsync` connections, prevents hot-spin on canceled streams, fixes `TimeProvider` timestamp unit mismatch, makes `KableLocalizer` thread-safe, ref-counts `SingleFlightConcurrencyGuard` lock eviction, hardens `NamedPipe`/`Tls`/`SerialPort` cleanup, normalizes `PcapWriter` UTC timestamps with buffer reuse, completes OTel metric channels on dispose, and validates `SpscRingBuffer` capacity.
- **Protocols & Transports**: Validates outbound 16-bit frame lengths in MELSEC SLMP and Modbus TCP; fixes gRPC server stream/CTS leaks, client connect token lifetime, and 5-RPC auth header immutability; enforces Fail-Fast `DeviceDisconnectedException` on disconnected MQTT QoS 1/2 publishes (logging and dropping QoS 0), adds MQTT TLS/credential options, and cleans up previous OPC UA `KeepAlive` handlers/sessions on reconnect.
- **Source Generators (`Kable.Generators`)**: Restores Roslyn incremental caching via value-equatable `CommandModel`, emits per-command outputs with `FormattableString.Invariant`, reports `KABLEGEN001` for non-partial targets, fixes root-level ProtocolPack file binding, control-character escaping, C# keyword escaping, and unique constant/enum collision loops.
- **WPF & ConfigStudio (`Kable.UI.Wpf`, `Kable.ConfigStudio`)**: Fixes duplicate periodic telemetry logging and missing engineering units, wires `FilterText` filtering on telemetry/alarm views, batches `RawPacketLogStreamViewModel` updates on a 50 ms dispatcher timer, eliminates UI-thread blocking in `VirtualDeviceSimulator.Stop()` and serial port live tests, extracts shared `PacketLogGrid` and frozen theme brushes (`po:Freeze="True"`), and adds `Kable.UI.Wpf.Tests`.

## Packaging & Build

- Adopts Central Package Management (`Directory.Packages.props`) with TFM-aligned `Microsoft.Extensions.*` (`8.0.0` on `netstandard2.0`/`net8.0`, `10.0.8` on `net10.0`) and GA `System.IO.Ports`.
- Publishes XML documentation files (`lib/*/*.xml`), symbol packages (`.snupkg`), portable PDBs, and built-in .NET SDK SourceLink across all library packages.
- Marks the legacy `OpcUaClientBridge(string, ...)` constructor and four unimplemented generator attributes (`[DeviceCommandReply]`, `[DeviceRpc]`, `[DeviceStream]`, `[DeviceAlarm]`) `[Obsolete]` while preserving source/binary compatibility.

## Upgrade Guidance

- **LaunchGuard**: Populate `AllowedExecutables` explicitly before enabling `PathAndHashLaunchGuard`.
- **IPC Named Pipes**: For Windows Service ↔ Interactive UI deployments across accounts, pass `currentUserOnly: false` to the new `IpcNamedPipe` constructor overload.
- **MQTT QoS 1/2**: Disconnected `PublishMetricAsync` / `PublishRawAsync` calls with QoS 1 or 2 now throw `DeviceDisconnectedException` instead of silently succeeding.
- **GuardedProcessLauncher**: Set `LaunchCommand.RedirectStandardStreams = true` explicitly if capturing stdout/stderr.
