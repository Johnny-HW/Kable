# Kable 1.10.1 릴리즈 노트

2026-10-29. 제품 패키지 14개를 NuGet.org와 GitHub Packages에 게시 완료. [빌드·테스트·패키지 검증](https://github.com/Johnny-HW/Kable/actions/runs/40816337009).

## 수정 사항

- 응답 확정 전 송신 로깅이 실패하면 FIFO 세션을 안전하게 종료한다.
- 타임아웃 로그 또는 메시지 ToString 실패에도 FIFO DeviceTimeoutException을 보존한다. 진단 오류는 Exception.Data에 기록한다.
- Ping 송신이 정체되어도 하트비트 감시를 유지하고, Ping 생성 실패 시 연결을 종료한다.
- 바이너리 송신 전에 설정된 최대 크기와 2바이트 길이 필드의 범위를 검증한다.
- .NET 8/10 요청 제한시간에 설정된 TimeProvider를 적용한다. netstandard2.0은 기존 시스템 타이머를 유지한다.

공개 인터페이스와 지원 프레임워크는 유지한다. 잘못된 길이를 가진 송신 데이터는 이제 ArgumentOutOfRangeException으로 거부한다.
회귀 테스트로 관찰자·문자열 변환 실패, Ping 송신 정체와 길이 경계를 검증한다. 실장비·장기간 부하 시험은 포함하지 않는다.
